# Minsk Air Radar — тестовый билд

Мобильный веб-прототип карты воздушной обстановки вокруг Минска.

## Развёртывание
1. Распакуйте архив.
2. Загрузите содержимое репозитория в GitHub.
3. Импортируйте репозиторий в Vercel и нажмите Deploy. Сборка не требуется.
4. Откройте адрес Vercel на смартфоне.

## Важно
- Источник — публичный OpenSky API, без ключа; возможны ограничения, задержки и отсутствие части бортов.
- Обновление интерфейса раз в 15 секунд; запросы к источнику кэшируются на сервере.
- Это демонстрационный инструмент, не предназначенный для оперативного управления воздушным движением или принятия критически важных решений.
- Карта использует тайлы OpenStreetMap и библиотеку Leaflet через CDN; для полноценного офлайн-режима и production-эксплуатации нужны отдельные решения.
